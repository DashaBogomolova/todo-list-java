# Task Manager (Console Version)

Простое консольное приложение для управления списком задач. Реализовано на чистой Java с разделением на слои: UI, Service, Repository.

## Функционал
- Просмотр всех задач
- Создание задачи (описание + приоритет)
- Редактирование задачи
- Отметка задачи как выполненной
- Удаление задачи

## Запуск
1. Убедитесь, что установлена JDK 17 или выше.
2. Клонируйте репозиторий.
3. Откройте проект в IntelliJ IDEA.
4. Запустите класс `Main`.

## Структура
- `Main` – точка входа
- `TaskConsoleUI` – консольный интерфейс
- `TaskService` – бизнес-логика
- `TaskRepository` – хранение в памяти (ArrayList)
- `Task` – модель задачи
- `Priority` – перечисление приоритетов

### Технологии: Java 17, Git, Collections Framework.
